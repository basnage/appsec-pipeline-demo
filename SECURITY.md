# Security Policy

This repository is a **deliberately vulnerable demonstration**. The application,
Dockerfile and Terraform contain intentional security flaws so that the CI
pipeline has real findings to report. They are documented in README.md.

Please do not report those planted issues.

If you find a real problem with the **pipeline itself** (`.github/workflows/`,
`scripts/`, `rules/`), for example a way to abuse the workflow, please open a
private report via **Security → Report a vulnerability** on this repository.
